Dieses Repository hält das Organisationsprofil der **Industrieservice SH GmbH**.

`profile/README.md` ist die Seite, die GitHub unter
[github.com/Industrieservice-SH](https://github.com/Industrieservice-SH) anzeigt.

`social_media/templates/github-banner.html` im Website-Repository und folgen dem
Brand-Asset-Sheet: Stahlblau `#475775`, Gold `#ecb030`, Jost und Montserrat.
