## Ein Unternehmen, zwei Welten

Die **Industrieservice SH GmbH** aus Flensburg vereint zwei Bereiche, die sonst
getrennt eingekauft werden: klassischen Maschinen- und Anlagenbau auf der einen
Seite, Managed IT, Produktions-IT und KI-Beratung auf der anderen.

Für unsere Kunden heißt das: ein Ansprechpartner, der die Werkshalle genauso
versteht wie den Serverraum. Hier auf GitHub liegt die Software, mit der wir das
tun.

## Was wir machen

**Betreiben.** Cloud und Hosting, Server und Netzwerk, Microsoft 365, Monitoring,
Anwendersupport.

**Absichern.** Backup und Wiederherstellung, Firewall und Endpoint-Schutz,
E-Mail-Sicherheit, Notfallvorsorge.

**Beraten.** KI-Enablement, IT-Strategie, Prozessoptimierung, NIS2 und Compliance.

**Produktions-IT.** Netzsegmentierung, Absicherung von Altsystemen, Monitoring von
Produktionsanlagen.

**Industrieservice.** Maschinenbau, Verpackungstechnik, Ersatzteile,
Ingenieurdienstleistungen.

## Was hier liegt

Die Repositories dieser Organisation sind überwiegend privat. Sie enthalten
Kundenprojekte und interne Werkzeuge, unter anderem:

- **Auswertung aus der Produktion.** Oberflächeninspektion über vier Linien,
  automatisch gegen die Produktspezifikation geprüft. Der Zugriff auf die
  Inspektionsrechner ist im Code auf Lesen beschränkt, nicht über eine Freigabe.
- **Fachanwendungen für Kunden.** Software für Abläufe, für die es nichts von der
  Stange gibt.
- **Odoo-Module** für die eigene Verwaltung.
- **Ein Einrichtungspaket für Arbeitsplätze.** Ein Befehl richtet eine Maschine
  für Linux, Netze und Kundenserver fertig ein.
